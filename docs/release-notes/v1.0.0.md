# Macro Pad 1.0.0

The first public release of the Macro Pad desktop app, for a handmade ESP32-C3 macro pad
with 12 keys and 2 clickable knobs.

## Download

| File | For |
|---|---|
| `MacroPad-Setup-1.0.0.exe` | Windows 10 / 11 (64-bit) |
| `MacroPad-1.0.0-macOS.dmg` | macOS on Apple Silicon (tested on macOS 15) |

**Windows note:** the installer isn't code-signed, so SmartScreen may show "Windows protected
your PC". Click **More info → Run anyway**.

**macOS note:** open the `.dmg` and drag **Macro Pad** onto **Applications**. The app isn't
notarized, so the first time go to **System Settings → Privacy & Security → Open Anyway**,
then allow it under **Accessibility** so it can send shortcuts. It runs from the menu bar
(no Dock icon).

## What's included

- Assign any keyboard shortcut, media key (volume, mute, play/pause) or scroll to every key
  and knob, by clicking it on a drawing of the pad.
- Labels for every control, and live feedback as you press.
- Profiles: add, rename, delete, import, export and lock.
- Automatic profiles that follow the app in front; any app can be assigned to any profile.
- Runs in the tray: closing the window keeps it working, and **Quit** is in the tray menu.
- Optional start at sign-in (in the installer and in the tray menu).
- A ready-to-use starter set of mappings on first install (General + Browser).
- Installer for all users, with a desktop shortcut option. Upgrades keep your settings, and
  uninstalling removes the start-at-sign-in entry.

## Firmware

The ESP32-C3 firmware source is in [`firmware/`](https://github.com/FhmSalah/M_Pad/tree/main/firmware)
(PlatformIO; build and flash instructions in its README).

## Requirements

- The Macro Pad (or any ESP32-C3 board running firmware that speaks the documented
  [message format](https://github.com/FhmSalah/M_Pad#message-format-pad--app)).
- USB connection. No driver is needed on Windows 10 / 11.
